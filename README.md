# 宝可梦大战僵尸 (Pokemon vs Zombies)

植物大战僵尸玩法的像素风网页游戏，宝可梦皮肤版。

## 玩法

- **皮卡丘 (50⚡)**：代替向日葵，每 7 秒产出 25 电能
- **小火龙 (100⚡)**：代替豌豆射手，发射火球并点燃灼烧
- **妙蛙种子 (50⚡)**：肉盾，挡住僵尸去路
- **杰尼龟 (175⚡)**：水弹攻击并减速，与火系触发蒸发反应

## 特色

- 🧪 **元素反应**（借鉴塞尔达传说：旷野之息）：火球点燃、水弹湿润；水火相触触发**蒸发**——火球打湿润僵尸伤害 ×2.5，水弹浇灭燃烧僵尸 +25 伤害
- 👾 5 种僵尸（普通 / 路障 / 铁桶 / 疾跑 / 巨尸王 Boss），10 波通关 + 无尽模式
- ⚾ 每行一次精灵球守卫（代替除草机）
- 🎮 手机掌机手柄（十字键 + ABXY）与触屏、键盘全支持；横竖屏自适应
- 🔊 WebAudio 合成音效，零依赖单文件

## 操作

| 输入 | 操作 |
|---|---|
| 触屏 | 点卡片选宝可梦 → 点草地放置 |
| 手柄 | X 换卡 · A 放置 · B 取消 · Y 铲子 · 十字键移动光标 |
| 键盘 | WASD 移动 · Z 放置 · X 取消 · C 换卡 · V 铲子 · 1~4 选卡 · P 暂停 |
